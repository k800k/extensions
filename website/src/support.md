## Before reporting a defect

1. Confirm whether the failure is in MangaReader itself, an extension, or the external service.
2. Reproduce the problem with the latest published package.
3. Search existing issues for the extension ID and service name.
4. Record the MangaReader version, extension version, catalog URL, expected result, actual result, and exact steps.
5. Remove credentials, reading history, tokens, and other private information.

## Service outages

An extension cannot repair an external service that is offline, blocking your network, or changing its own interface. Confirm the service is lawfully accessible in a normal browser before filing an extension defect.

## Security reports

Never put access tokens, publisher keys, exploitable package details, or personal data in a public issue. Follow the [Security Policy](https://github.com/k800k/extensions/blob/main/SECURITY.md) for private disclosure.
