# Review status for HitomiLA

Availability is **available**. Sanitized tests cover Nozomi byte decoding, range cursors, language and namespaced query parsing, title-index traversal, structural metadata parsing, WebP routing, configuration caching, bounded concurrency, and malformed response rejection.

Users should inspect the adult-content and unresolved rights records, current upstream binary-format compatibility, and runtime smoke evidence before installing. Routing configuration is treated as untrusted data and cannot add a new host to the declared access boundary.
